# Maisie's Farm

Game nông trại bên bờ biển cho bé Maisie, chơi trên điện thoại (iPhone và Android) và máy tính.

**Chơi tại:** https://lehuynhkhuongduy.github.io/maisies-farm/

## Cài lên điện thoại
- **iPhone/iPad:** mở link bằng Safari → nút Chia sẻ → "Thêm vào MH chính".
- **Android:** mở link bằng Chrome → menu ⋮ → "Cài đặt ứng dụng" (hoặc "Thêm vào màn hình chính").

Sau lần mở đầu tiên, game chơi được cả khi không có mạng. Tiến độ lưu trên từng máy.

## Cách chơi
- Chạm ô ruộng trống để chọn hạt giống, kéo ngón tay qua nhiều ô để gieo liền. Cây chín thì chạm hoặc kéo qua để thu hoạch.
- Máy xay làm thức ăn cho gà, bò, heo. Chạm chuồng để cho ăn, rồi chạm lại để nhặt trứng, sữa, nấm.
- Nhà máy (lò bánh, xưởng sữa, quầy nước ép, bếp nấu) biến nông sản thành món ngon.
- Giao hàng ở bảng đơn hàng và đóng thùng lên tàu để nhận xu, sao, kim cương.
- Dọn bụi cây, tảng đá bằng năng lượng để mở rộng đất. Giữ lâu một công trình để di chuyển nó.

## Phát triển
```bash
npm install
npm run dev
```
Đăng bản mới lên GitHub Pages: `npm run deploy` (build rồi đẩy thư mục `dist` lên nhánh `gh-pages`).
